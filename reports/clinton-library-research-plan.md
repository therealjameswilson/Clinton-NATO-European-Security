## Basis

This plan incorporates the four local Clinton Library finding-aid PDFs supplied
for release `2013-0185-M`:

- `2013-0185-M_Part1.pdf` (375 pages)
- `2013-0185-M_Part2.pdf` (376 pages)
- `2013-0185-M_Part3.pdf` (356 pages)
- `2013-0185-M_Part4.pdf` (183 pages)

The PDFs list Clinton Presidential Records, National Security Council folder
titles by OA/ID number, folder title, and NSC office or staff file. The aim is
to maximize onsite time by converting the finding aids into a pre-visit pull
queue for *FRUS, 1993-2000, Volume XVII, North Atlantic Treaty Organization;
European Security*.

## Research Logic

Do not start with the largest crisis folders. The existing corpus is already
overweight on Bosnia and Kosovo. Start with files most likely to close the
compiler gaps identified in `compiler-gap-analysis.md`: NATO institutional
traffic, CFE, OSCE/CSCE, Partnership for Peace, NATO-Russia, NATO-EU/ESDI, and
direct enlargement policy files.

## Onsite Workflow

1. Before the visit, ask Clinton Library staff whether the `2013-0185-M` OA/ID
   folders can be pre-pulled, whether any folders are fully or partly withdrawn,
   and whether there are daily pull or scanning limits.
2. Use the first pull for European Affairs policy-core folders before
   speechwriting or broad crisis folders.
3. For every folder opened, photograph or transcribe the folder title, OA/ID
   number, collection path, withdrawal sheets, and first/last page before
   extracting document images.
4. Promote only document-level items into the public corpus after recording
   actual date, sender/recipient or meeting participants, page span, markings,
   release status, and source-note path.
5. Use Executive Secretary trip books and PC/DC files to settle chronology, then
   use Speechwriting files as public-text controls rather than as the main
   documentary base.
6. Keep a same-day decision log: include candidate, context only,
   duplicate/source-control, or no action.
